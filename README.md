# 나의 5K — 1차 테스트 버전

## 들어 있는 기능
- 아이폰 GPS로 이동거리 측정
- 운동시간 측정
- 평균 페이스 계산
- 현재 속도 표시
- 3분 걷기 → (5분 달리기 + 1분 걷기) × 5 → 3분 걷기
- 구간 전환 시 소리 + 한국어 음성 안내
- 운동 종료 후 거리 / 시간 / 평균 페이스 요약

## 중요한 제한
아이폰 Safari/PWA는 화면이 꺼지거나 앱이 백그라운드로 가면 GPS와 자바스크립트 타이머가 중단될 수 있습니다.
따라서 1차 테스트는 화면을 켠 상태에서 사용해 보세요.

## 실행 방법
GPS는 보안상 `file://`로 직접 열면 제대로 동작하지 않을 수 있습니다.
반드시 HTTPS 웹사이트에 올려서 실행하는 것을 권장합니다.

가장 쉬운 방법 중 하나:
1. GitHub 계정을 만든다.
2. 새 저장소(repository)를 만든다.
3. 이 폴더의 index.html, manifest.json, sw.js를 업로드한다.
4. Settings → Pages에서 GitHub Pages를 켠다.
5. 생성된 HTTPS 주소를 아이폰 Safari로 연다.
6. 공유 버튼 → '홈 화면에 추가'를 누른다.
7. 처음 운동 시작 시 위치 권한을 '허용'한다.
